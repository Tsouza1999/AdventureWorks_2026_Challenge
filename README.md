## Tecnologias e Bibiliotecas
- Python
- SQL Server
- Pandas
- Streamlit
- Plotly

## Versões utilizadas no projeto
Python 3.10.11
SSMS Release 19.3
SQL Server Developer 19

Este projeto utiliza a base AdventureWorks, disponível em:

🔗 https://learn.microsoft.com/en-us/sql/samples/adventureworks-install-configure

Certifique-se de:

Realizar o Restore no SQL Server

## Como executar

1. Clone o repositório:
2. Instale as dependências:
```bash
pip install streamlit pandas pyodbc sqlalchemy matplotlib seaborn
python -m pip install streamlit

pip install -r requirements.txt
